# Studer - Student Management System (Redux Toolkit)

A modern, high-performance **Student Management System** built with **React 18** and **Redux Toolkit (`@reduxjs/toolkit`)**. Developed as part of the **Sheryians Coding School Mini Hackathon**.

## 🚀 Features

- **Full Student CRUD:** Add, Edit, Delete, and View Student records with form validation.
- **Real-Time Analytics Dashboard:** Displays total enrolled students, active count, graduated alumni count, and average GPA using `useSelector`.
- **Search & Filtering:** Live search by student name, roll number, email, or course, plus course and status filters.
- **View Toggle:** Seamlessly switch between Grid view and List view.
- **LocalStorage Sync:** Persistence across page refreshes.
- **Dark Glassmorphic UI:** Modern design with micro-animations.

## 🛠️ Tech Stack

- **Frontend:** React 18
- **State Management:** Redux Toolkit (`@reduxjs/toolkit`), `react-redux`
- **Build Tool:** Vite
- **Icons:** Lucide React
- **Styling:** Vanilla CSS (Glassmorphism Dark Theme)

## 🏃 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/vedantwankhade123/Studer.git
   cd Studer
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
